The funniest one-line voicemail greeting a cat would record: Miso is busy knocking things off the shelf, so leave a message after the beep — or just open the tuna. Pure Python standard library, deterministic output.

## Run it

```sh
python3 main.py
```

This writes the single greeting line to `$OUTPUT_DIR/entry.txt` (default `/output`).
